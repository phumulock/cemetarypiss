# Go + templ + air Backend Scaffold — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up a Go server (chi + templ + air + Taskfile) that ports the existing `index.html` (kept untouched on disk) into templ components at `/`, plus a `/demo` page exercising every main method of the `datastar-go` SDK as a smoke test.

**Architecture:** chi for HTTP routing. templ compiles `.templ` files to `_templ.go` Go source. air watches `.go` and `.templ` files and re-runs `templ generate` + `go build` + restart on changes. Taskfile defines named entry points (`task dev`, `task build`, etc.). Layout is `cmd/server/main.go` + `internal/handlers/*.go` + `internal/views/*.templ`.

**Tech Stack:** Go 1.24+, chi (router), templ (templates), air (live-reload), Taskfile (commands), datastar-go (SSE backend SDK).

**Spec:** `docs/superpowers/specs/2026-05-26-go-templ-air-scaffold-design.md`

## Task 5: Create .air.toml

**Files:**
- Create: `.air.toml`

- [ ] **Step 1: Write .air.toml**

Create `.air.toml` with this exact content:

```toml
root = "."
tmp_dir = "tmp"

[build]
  pre_cmd = ["templ generate ./..."]
  cmd = "go build -o ./tmp/main ./cmd/server"
  bin = "./tmp/main"
  include_ext = ["go", "templ"]
  exclude_dir = ["bin", "tmp", "node_modules", ".git", "docs", ".claude"]
  exclude_regex = ["_templ\\.go$"]
  delay = 200

[log]
  time = true

[misc]
  clean_on_exit = true
```

Notes on this config (for your understanding, not to add as comments):
- `pre_cmd` runs `templ generate` before each build, so editing a `.templ` file regenerates `_templ.go` before `go build` runs.
- `exclude_regex = ["_templ\\.go$"]` is critical: it prevents air from treating the just-generated `_templ.go` files as a change (which would re-trigger the build → infinite loop).
- `delay = 200` (ms) coalesces rapid saves.

## Task 10: Create the demo SSE handlers

**Files:**
- Create: `internal/handlers/demo.go`

These five handlers each exercise one method of the datastar-go SDK.

- [ ] **Step 1: Write demo.go**

Create `internal/handlers/demo.go` with this exact content:

```go
package handlers

import (
	"fmt"
	"html"
	"net/http"
	"time"

	"github.com/starfederation/datastar-go/datastar"
)

type bumpStore struct {
	Count int `json:"count"`
}

// DemoBump reads $count, increments, and patches it back via signals.
// Exercises: ReadSignals + MarshalAndPatchSignals.
func DemoBump(w http.ResponseWriter, r *http.Request) {
	var s bumpStore
	if err := datastar.ReadSignals(r, &s); err != nil {
		http.Error(w, err.Error(), http.StatusBadRequest)
		return
	}
	sse := datastar.NewSSE(w, r)
	sse.MarshalAndPatchSignals(map[string]any{"count": s.Count + 1})
}

// DemoTime morphs #server-time with the current server timestamp.
// Exercises: PatchElements (default outer morph by id).
func DemoTime(w http.ResponseWriter, r *http.Request) {
	sse := datastar.NewSSE(w, r)
	sse.PatchElements(fmt.Sprintf(
		`<div id="server-time">%s</div>`,
		html.EscapeString(time.Now().Format(time.RFC1123)),
	))
}

// DemoNote appends a new <li> into #notes.
// Exercises: PatchElements with ElementsModeAppend.
func DemoNote(w http.ResponseWriter, r *http.Request) {
	sse := datastar.NewSSE(w, r)
	sse.PatchElements(
		fmt.Sprintf(`<li>note added at %s</li>`, html.EscapeString(time.Now().Format(time.Kitchen))),
		datastar.WithSelector("#notes"),
		datastar.WithMode(datastar.ElementsModeAppend),
	)
}

// DemoDismiss removes the #banner section.
// Exercises: RemoveElement.
func DemoDismiss(w http.ResponseWriter, r *http.Request) {
	sse := datastar.NewSSE(w, r)
	sse.RemoveElement("#banner")
}

// DemoGreet runs an alert in the browser.
// Exercises: ExecuteScript.
func DemoGreet(w http.ResponseWriter, r *http.Request) {
	sse := datastar.NewSSE(w, r)
	sse.ExecuteScript(`alert("hello from server")`)
}
```

```go
package main

import (
	"log"
	"net/http"

	"github.com/go-chi/chi/v5"
	"github.com/go-chi/chi/v5/middleware"

	"github.com/phumulock/cemetarypiss/internal/handlers"
)

func main() {
	r := chi.NewRouter()
	r.Use(middleware.Logger)
	r.Use(middleware.Recoverer)

	// Pages
	r.Get("/", handlers.Home)
	r.Get("/demo", handlers.DemoPage)

	// Demo SSE endpoints
	r.Post("/demo/bump", handlers.DemoBump)
	r.Post("/demo/time", handlers.DemoTime)
	r.Post("/demo/note", handlers.DemoNote)
	r.Post("/demo/dismiss", handlers.DemoDismiss)
	r.Post("/demo/greet", handlers.DemoGreet)

	// Audio assets (kept at project root for index.html compatibility)
	r.Get("/audio/01-intro.mp3", func(w http.ResponseWriter, req *http.Request) {
		http.ServeFile(w, req, "./01 - Intro.mp3")
	})
	r.Get("/audio/04-terrorvoid.mp3", func(w http.ResponseWriter, req *http.Request) {
		http.ServeFile(w, req, "./04 - Terrorvoid.mp3")
	})

	// Future static assets (CSS, images, optional extracted JS)
	staticFS := http.FileServer(http.Dir("./static"))
	r.Handle("/static/*", http.StripPrefix("/static/", staticFS))

	addr := ":8080"
	log.Printf("listening on http://localhost%s", addr)
	log.Fatal(http.ListenAndServe(addr, r))
}
```
